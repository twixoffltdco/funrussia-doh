# 01 — DoH / Layero

**Целевой проект:** `twixoffltdco/funrussia-doh`  
**Целевой хост:** `https://funrussia-doh.layero.dev/dns-query`

В этой папке находятся заметки по интеграции, а не новый серверный код. В текущем проекте уже упоминался `server.js` с Cloudflare upstream и переменной окружения `HIJACK`. Его реальное содержимое нужно сохранить и проверить в репозитории.

## Назначение
DoH обслуживает DNS-запросы. Переопределение домена с помощью `HIJACK` работает только для запросов этого домена через данный resolver. Оно не перенаправляет прямые соединения к `185.207.214.14`.

## Перед деплоем
1. Открой существующий репозиторий и проверь `server.js`, `package.json`, стартовую команду и переменные окружения.
2. Не заменяй существующий `server.js` этим README.
3. Проверь health endpoint и `/dns-query` после деплоя.
4. Не направляй `api.blackrussia.online` на игровой IP без подтверждения, что там действительно обслуживается ожидаемый API и корректно настроен TLS. Иначе официальная игра может перестать подключаться.
